# EMG-ON : 근전도 기반 운동 수행 모니터링 시스템

표면 근전도(sEMG) 기반 근활성 분석 및 운동 수행 모니터링 서비스

## 프로젝트 소개

운동이나 재활 과정에서는 단순히 정해진 횟수를 수행하는 것뿐만 아니라,
운동 중 실제로 근육의 활성 신호가 어떻게 나타나는지를 확인하는 것도 중요합니다.

하지만 일반 사용자가 운동 중 자신의 근활성 변화를 직접 확인하기는 어렵고,
전문적인 근전도 원시 데이터 역시 비전문가가 그대로 이해하기 어렵습니다.

"EMG-ON"은 표면 근전도(sEMG) 센서를 이용하여
운동 중 측정 부위에서 발생하는 근전도 신호를 실시간으로 수집하고,
개인별 기준값에 따라 신호를 분석하여
근활성 구간, 수축 지속시간, 반복 수행 횟수, 운동 수행률 등의
정보를 사용자가 이해하기 쉬운 형태로 제공하는 운동 수행 모니터링 시스템입니다.

## 해결하고자 하는 문제

- 운동 중 근활성 변화를 사용자가 직접 확인하기 어려움
- 전문적인 EMG 원시 데이터를 일반 사용자가 해석하기 어려움
- 단순 반복 횟수만으로는 근수축 수행 양상을 확인하기 어려움
- 사람마다 다른 근전도 신호 크기로 인해 동일한 절대 기준 적용이 어려움
- 운동 수행 기록을 지속적으로 확인하고 비교하기 어려움

## 핵심 기능

### 1. 실시간 EMG 신호 측정

표면 근전도 센서와 Arduino를 이용하여
운동 중 발생하는 EMG 신호를 실시간으로 수집합니다.

### 2. 개인별 기준값 설정

사람마다 근전도 신호의 크기가 다르기 때문에
모든 사용자에게 동일한 절대 임계값을 적용하지 않습니다.

측정 전 안정 상태와 기준 수축 상태의 신호를 측정하여
사용자 개인의 기준값을 설정하고,
운동 중 나타나는 신호 변화를 개인별 기준에 따라 분석합니다.

### 3. 근활성 구간 검출

개인별 기준값과 최소 지속시간 등의 조건을 이용하여
운동 중 근활성 신호가 나타나는 구간을 검출합니다.

순간적인 신호 변화만으로 수축을 판단하지 않고,
일정 조건을 만족한 활성 구간과 이후 이완 구간을 함께 분석합니다.

### 4. 운동 반복 횟수 측정

검출된 근활성 및 이완 구간을 바탕으로
유효한 근수축 반복 횟수를 계산합니다.

### 5. 운동 수행 정보 제공

측정된 데이터를 바탕으로 다음과 같은 정보를 제공합니다.

- 유효 반복 횟수
- 목표 반복 횟수
- 운동 수행률
- 근수축 지속시간
- 이완시간
- 개인 기준 대비 근활성 변화

### 6. 실시간 데이터 시각화

운동 중 측정되는 EMG 신호를 그래프로 표시하고,
현재 근활성 상태와 반복 횟수를 실시간으로 확인할 수 있도록 합니다.

### 7. 운동 기록 저장 및 조회

사용자별 운동 세션 결과를 저장하여
이전 운동 기록과 수행 변화를 확인할 수 있도록 합니다.

### 8. 운동 콘텐츠 추천

운동 부위와 수행 결과를 기반으로
사전에 등록된 운동 콘텐츠 중 적절한 콘텐츠를 제공합니다.

외부 영상을 사용하는 경우 영상을 직접 저장하지 않고,
공식 임베드 또는 허용된 방식으로 연결하는 구조를 사용합니다.

## 주요 분석 기능

### 개인별 기준값 설정

사용자별 EMG 신호 특성을 고려하여
측정 전 개인 기준값을 설정합니다.

### 근활성 구간 검출

개인별 기준값과 신호 지속시간을 이용하여
근활성 구간과 이완 구간을 구분합니다.

### 반복 수행 검출

근활성 → 이완으로 이어지는 신호 패턴을 분석하여
유효한 반복 수행 횟수를 계산합니다.

### 운동 수행률 계산

목표 반복 횟수와 실제 유효 반복 횟수를 비교하여
운동 수행률을 계산합니다.

예시:

목표 반복 횟수 : 10회
유효 반복 횟수 : 8회

운동 수행률 : 80%

## 차별점

기존의 일반적인 운동 기록 서비스는
사용자가 직접 입력한 운동 횟수나 시간 등의 정보를 중심으로 기록합니다.

"EMG-ON"은 표면 근전도 센서를 통해 실제 생체신호를 측정하고,
전문적인 EMG 원시 데이터를 일반 사용자가 이해할 수 있는
운동 수행 정보로 변환하는 것을 목표로 합니다.

단순히 "운동을 했는가"를 기록하는 것을 넘어,

- 근활성 신호가 언제 발생했는지
- 근수축이 얼마나 지속되었는지
- 몇 번의 유효한 수축이 발생했는지
- 목표 운동을 어느 정도 수행했는지

등을 정량적인 데이터로 확인할 수 있도록 합니다.

## 시스템의 범위 및 제한사항

EMG-ON은 의료 진단 시스템이 아닙니다.

표면 근전도 센서를 통해 측정 부위에서 획득한 전기적 신호를 기반으로
근활성 양상과 운동 수행 정보를 분석하는 것을 목적으로 합니다.

따라서 다음과 같은 판단에는 사용하지 않습니다.

- 질환 진단
- 근육 전체의 상태 판단
- 골절 및 관절 손상 판단
- 정상/비정상 판정
- 치료 효과 판정

또한 EMG 신호는 센서 부착 위치, 피부 상태, 움직임,
개인별 신체 특성 등에 영향을 받을 수 있으므로
개인별 기준값 설정과 신호 품질 확인 과정을 적용합니다.
